# API reference

Functions grouped by topic.

- [Core](core.md) — Low-level function for querying any API endpoint.
- [Endpoint catalog](catalog.md) — Discover endpoints and inspect input/output fields from the built-in catalog (offline).
- [Cache](cache.md) — Manage the in-memory result cache.
- [Configuration](config.md) — Runtime settings (also configurable via TCEPEPY_* environment variables).
- [Revenues](revenues.md) — State and municipal revenue data.
- [Expenditures](expenditures.md) — State and municipal expenditure data.
- [Budget commitments](commitments.md) — Commitment (empenho) summaries, liquidations, payments and line items.
- [Suppliers](suppliers.md) — Supplier registry and sanctions.
- [Procurement & contracts](procurement.md) — Bids, contracts, amendments, agreements and related lookup tables.
- [Public works](public-works.md) — Engineering works, contractors, audits and school transport.
- [Legal processes](processes.md) — Processes, determinations, recommendations, outcomes, debts, fines and spending limits.
- [Personnel](personnel.md) — Public servant records.
- [Reference tables](reference-tables.md) — Municipalities, managed entities, sub-units, creditor types, payroll types, funding sources and inactivation reasons.
- [RemessaTCEPE](remessa.md) — Data from the RemessaTCEPE system: benefit types, reference sources/dates/codes, update indices, budget statuses, legal instruments, procurement processes and works.
